# Contributing to `boox-book-notes`

Contributions are not expected, but they're certainly welcome!
This is mostly a project to help me bring my Boox tablet and Roam Research workflows together, but if you have similar needs, I'd love to share ideas and credit will always be given.

I sketeched this out manually, but most of the code is LLM-generated, so it might be more effective to just have an LLM write your code if your workflow differs greatly from mine.
